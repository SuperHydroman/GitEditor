## About

A long-term passion project aimed at recreating the [JetBrains Rider](https://www.jetbrains.com/rider/) IDE from scratch using C# and WPF. This serves as the ultimate learning exercise — pushing my understanding of UI development, software architecture, and IDE tooling to its limits.

## Motivation

As I progress through my C# learning journey, I wanted a single ambitious project that would:

- Challenge me at every stage of my development as a programmer
- Provide a real-world, complex application to reverse-engineer and rebuild
- Deepen my understanding of WPF, MVVM, and desktop application architecture
- Give me hands-on experience with text editors, parsers, and developer tooling

## Tech Stack

| Technology | Purpose |
|-----------|---------|
| C# | Primary language |
| WPF | UI framework |
| .NET | Runtime |
| MVVM | Architecture pattern |

## Building

```bash
git clone https://github.com/SuperHydroman/GitEditor.git \
cd ./GitEditor \
dotnet build \
dotnet run
```
